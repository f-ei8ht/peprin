## Timeline

- Multi-track timeline with video, audio, text, sticker, and subtitle track types
- Drag-and-drop media from library onto timeline tracks
- Clip trimming via edge drag with snap-to-neighbor
- Ripple mode for automatic gap closing
- Zoom from 3 px/s to 600 px/s via slider, wheel, and keyboard
- Snapping to clip edges, playhead, and grid intervals
- Virtualized clip rendering for projects with 1000+ clips

## Preview

- Real-time preview canvas using OffscreenCanvas compositor
- Play/pause, frame-forward/back, jump-to-start/end controls
- Scrubbing via timeline ruler and direct canvas drag
- Fit, fill, and percentage zoom modes
- Aspect ratio aware with configurable frame rate

## Inspector

- Per-clip property panel for position, scale, rotation, opacity
- Real-time parameter binding that updates preview within 50ms
- Speed and retime controls (0.1x to 10x)
- Effect and mask management per clip

## Commands

- Full undo/redo stack (200 commands)
- Cut, copy, paste, duplicate via clipboard
- Keyboard shortcuts: Space, JKL shuttle, Ctrl+Z/X/C/V/D, Delete, S for split
